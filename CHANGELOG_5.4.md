# Ask Crump 5.4 — Durable Deliverables

Ask Crump 5.4 turns large requests into workspaces that can survive a chat window.

When a user asks for a full book, memoir, screenplay, dissertation, or other book-scale work, Crump now creates a persistent Project, builds a complete chapter blueprint, records the target length and continuity burden for each chapter, and returns an Open workspace card in the conversation. The author can review the plan, draft the next unfinished chapter, revise individual sections, watch word-count progress, and export KDP-aware DOCX/PDF or Kindle EPUB files.

Ordinary file requests remain immediate. Natural phrases such as “write this and send it as a Word document” now route to the existing artifact generator, with Document and Manuscript modes visible beside the composer.

This release also restores those product layers to the native bundle and separates internal QA access from paid subscription state so launch testing does not falsify billing data.
