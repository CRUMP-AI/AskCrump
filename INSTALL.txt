INSTALL
1. Extract this ZIP.
2. Copy EVERYTHING INSIDE the extracted folder into the ROOT of CRUMP-AI.
3. Choose Merge/Replace when prompted.
4. Open GitHub Desktop and review the changes.
5. Commit with exactly:
   Rebuild Ask Crump V1 application body
6. Push.
7. Wait for GitHub checks and Vercel to reach READY.
8. Open https://askcrump.com/app in a NEW browser tab for the first web test.
9. Fully close/reopen the installed PWA once so the new service-worker namespace activates.
