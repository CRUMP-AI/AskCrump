ASK CRUMP — BRANDING FREEZE HOTFIX

ROOT CAUSE
The previous branding integration watched the entire DOM and unconditionally
replaced the sidebar branding inside that observer. Replacing the sidebar
created another DOM mutation, which triggered another replacement indefinitely.

THIS HOTFIX
- Makes header/sidebar branding updates idempotent.
- Removes the self-triggering MutationObserver loop.
- Watches only newly-added auth/empty-state nodes that genuinely need branding.
- Preserves the canonical logo placement and assets.
- Bumps the service-worker cache so Safari can replace the bad cached JS.

INSTALL
1. Extract this ZIP.
2. Copy the CONTENTS into the CRUMP-AI repository root.
3. Merge/Replace.
4. Commit and push.
5. Wait for Vercel READY.
6. On iPhone, fully close the Ask Crump tab/PWA and reopen it.
   If the first reopen still catches the old cached JS, close/reopen one more time.
