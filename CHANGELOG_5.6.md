# Ask Crump 5.6 — Store-Debut Product Polish

Ask Crump 5.6 is a product-quality release rather than a new provider release. It keeps the 5.5 backend, billing, storage, Projects, manuscripts, and video architecture intact while making the interface easier to understand and more consistent across web and the upcoming native apps.

The release introduces one final-authority polish layer, a current product tour, first-class Projects and Video launch actions, a cleaner Projects & Create studio, normalized video result controls, improved mobile typography and touch targets, a refreshed Clever Crump parent-company page, and updated store-facing product copy.

The runtime also stops relying on onboarding to load the old 4.3 compatibility layer. That dependency is now loaded deterministically before later UI layers on both web and native builds.
