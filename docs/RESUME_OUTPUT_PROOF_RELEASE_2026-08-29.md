# Ask Crump 5.9.74 résumé output-proof release

Date: 2026-08-29

Production version: 5.9.74

Feature commit: `fd95c32`

Production deployment: `dpl_Fmwqk27Pbsph6xa5peF3ABp4gdvN`

## Accountable outcome

Let a prospective résumé user inspect a representative result before creating an account, while
keeping the proof truthful, synthetic, editable in origin, and clearly separate from a customer
testimonial or guaranteed outcome.

The release does not claim conversion or résumé-quality lift. Its accountable delivery outcome is
that the public résumé page no longer asks a visitor to rely on copy alone.

## Evidence and source

The protected production growth funnel and artifact journey remained empty, so no external-account
behavior was invented and no synthetic production account or event was created. A comparison of
the public acquisition pages found a deterministic trust gap: the presentation page exposed
current rendered output, while the staged résumé campaign page described output without showing it.

The example was generated by Ask Crump's current Word exporter from the wholly fictional Jordan
Ellis product-operations brief already used by the internal artifact-quality script. The resulting
`.docx` was opened read-only in Microsoft Word, rendered to PDF, and rasterized at 1,275 by 1,650
pixels for complete visual inspection. The Word, PDF, and temporary render stayed outside the
repository; only the reviewed public PNG was added.

## Safety and scope boundaries

The release did not change:

- authentication, registration, verification, session authority, cookies, or account recovery;
- customer résumés, files, conversations, private Library data, prompts, or model routing;
- pricing, plans, credits, checkout, Stripe, RevenueCat catalog identifiers, or entitlements;
- Supabase schema, RLS, production analytics records, developer accounts, signing, or store
  submission.

The sample names, employers, school, contact details, dates, and metrics are fictional. Production
verification used public GET requests only and created no account, prompt, artifact, checkout, or
funnel mutation.

## Measurement decision

Treat `source=resume-proof` as a discoverable acquisition path, not proof of lift. Observe the
résumé page's first-party CTA and the protected `SignupIntent` → `SignupStarted` → verified
account → résumé artifact journey for at least 14 days and 50 qualified referred visitors before
attributing an effect. Diagnose any legitimate failed journey sooner, but do not create synthetic
production users or infer a platform click-through rate without impression data.
