# Code Studio — clickable prototype (v3)

Interactive design prototype for **Code Studio**, the coding agent built into Ask Crump.
Open `index.html` in a browser — it's fully self-contained (no build, no server).

## What's inside

- Full Ask Crump app shell: onboarding, Home, Chat, Projects, Library, Image/Video Studio, Canvas, Settings
- **Code Studio**: 3-pane studio on desktop (files | editor | preview), tabbed on phone
- Working write → run → fix loop: suggestion chips, thinking state, diff view with
  plain-language summaries, Accept/Discard, checkpoint timeline with one-tap Restore
- Demo project: a small portfolio site with 4 files
- Phone/Desktop toggle in the demo controls bar

## Design rules in this prototype

- Complete-message delivery with a calm thinking state (no typewriter, ever)
- Warm, plain-language copy — friendly, never intimidating
- Ink-black/gold skin; real logo artwork only
